## 云书景 (Yskye)

独立开发者。写代码的同时，喜欢把东西拆开看它到底是怎么跑的。

一直在两条线上走：一条往底层去——二进制、逆向、程序保护；一条往端上去——移动应用、小程序、Web。中间那条线是自己写的小工具，把两边缝在一起。

### 做过的事

**移动端。** iOS 原生、鸿蒙应用、微信小程序，三种端上都做过完整的项目。Swift 和 SwiftUI 写过，ArkTS 和 ArkUI 也写过。跨端和原生各自的账我算得清：什么场景该用原生、什么时候上跨端框架更划算，心里有数。

**逆向与安全。** CTF 逆向方向长期训练，静态分析和动态调试都走过一轮。IDA 脚本、脱壳、反混淆这些，与其等别人写，我习惯自己动手做一套。

**后端与自动化。** 从 Java / Vue 起家，现在更多用脚本和服务直接解决问题——自建网关、定时任务、数据管道。凡是一件事重复超过三次，我就会把它变成代码。

**AI 工程。** 把模型接进自己的工具链：上下文怎么给、协议怎么连、哪些活该交出去、哪些必须自己核对。踩过的坑比教程里写得多。

### 几条原则

- 能拆开的东西，就不当黑盒。
- 重复三次以上的操作，就该有脚本。
- 交付比炫技重要：能跑、能维护、能交给别人接手。
- 把话说清楚，比把代码写聪明更难。
