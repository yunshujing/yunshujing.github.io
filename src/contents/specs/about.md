## 云书景 (Yskye)

独立开发者。研究方向为二进制安全与程序分析，工程实践覆盖移动端、Web 与自动化基础设施。

### 技术领域

**逆向工程与二进制安全**

长期从事 CTF 逆向方向的研究与训练，熟悉静态分析、动态调试、脱壳与反混淆流程。具备自行开发分析工具的能力，包括 IDA 脚本与自动化分析管线。

**移动端开发**

具备 iOS（Swift / SwiftUI）、HarmonyOS（ArkTS / ArkUI）与微信小程序三端开发经验，能够依据业务场景在原生与跨端方案之间做出取舍。

**后端与基础设施**

以 Java、Vue 为起点，现主要从事服务端与自动化系统的设计与维护，包括 API 网关、定时任务、数据管道、备份与监控体系。

**AI 工程**

关注大模型在实际工程中的落地：上下文管理、工具协议接入、任务编排与结果校验。

### 工作原则

- 先理解原理，再使用工具。不将可分析的系统当作黑盒。
- 重复性的操作应当被自动化，而非依赖记忆执行。
- 交付优先于炫技：可运行、可维护、可交接。
- 表达的清晰度与代码的清晰度同等重要。
